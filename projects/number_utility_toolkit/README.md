# 🧮 Number Utility Toolkit (C++ CLI Mini Project)

A clean, interactive command-line mathematical utility built in C++ using modular functions.

---

## 🚀 Features

1. **Calculate nCr (Combination / Binomial Coefficient):**
   - Formula: \(nCr = \frac{n!}{r!(n - r)!}\)
   - Uses helper factorial function.

2. **Prime Number Checker:**
   - Evaluates whether an input integer \(N\) is prime.

3. **Sum of Digits Calculator:**
   - Extracts and sums all individual digits of an integer.

4. **Prime Number Range Generator:**
   - Generates and displays all prime numbers from 2 up to \(N\).

---

## 🛠️ How to Compile & Run

```bash
# Compile using g++
g++ main.cpp -o toolkit.exe

# Run the program
./toolkit.exe
```
