# 🎓 Student Practice System (C++ Console Application)

A comprehensive, modular console-based management and mathematical problem-solving toolkit built in C++ using functions, conditional logic, loops, and interactive CLI menus.

---

## 🚀 Key Modules & Features

1. **Student Information Management:**
   - Captures and displays student details (Name, Roll Number, Class).

2. **Marks & Grade Calculator:**
   - Computes total obtained marks across 5 subjects (English, Urdu, Mathematics, Chemistry, Biology) out of 500.
   - Calculates exact percentage using `double` typecasting.
   - Evaluates performance: Assigns Grade (A, B, C, D) and Pass/Fail status.

3. **Attendance Eligibility Checker:**
   - Evaluates total attendance against academic criteria (75% minimum threshold for 220 academic days).

4. **Multi-Condition Number Analyzer:**
   - Evaluates Even vs Odd numbers using modulus operator.
   - Evaluates Positive, Negative, or Zero states.
   - Evaluates Prime Number state using loops and boolean logic.

5. **Multiplication Table Generator:**
   - Dynamic table calculation demonstrating both `for` loop and `while` loop execution.

6. **Dynamic Pattern Generator:**
   - Generates sequential numerical right-angled triangles based on user-defined ranges.

7. **Interactive Navigation Menu:**
   - Menu-driven interface connecting all 6 modules with exit handling.

---

## 🛠️ How to Compile & Run

```bash
# Compile using g++
g++ main.cpp -o student_system.exe

# Run the program
./student_system.exe
```
